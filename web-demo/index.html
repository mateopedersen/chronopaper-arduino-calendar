HOW TO TRY IT

Navigate without losing the date model.

  • Use the arrows to change month; use the controls to change year and week origin.
  • Keyboard: ←/→ changes month, ↑/↓ changes year, and W toggles Monday/Sunday start.
  • ISO week labels follow ISO 8601 and can belong to the adjacent week-year.
  • The embedded device runs its date engine offline. NTP and a valid optional RTC only provide time-of-day.
